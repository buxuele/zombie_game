# 核心玩法与物理引擎架构

1. 60Hz 累加器固定物理步长与渲染解耦：在 [Game.js](file:///Users/fanchuang/Documents/zombie_game/src/engine/Game.js) 中实现确定性固定时间步长累加器，确保在 60Hz、120Hz 以及任何高刷屏幕或掉帧环境下物理与跳跃高度绝对一致。
2. 敏捷波浪跳跃与长按滑翔体系：在 [Zombie.js](file:///Users/fanchuang/Documents/zombie_game/src/entities/Zombie.js) 与 [ZombieHorde.js](file:///Users/fanchuang/Documents/zombie_game/src/entities/ZombieHorde.js) 中实现 800 重力加速度与 480 起跳冲量。支持短按快速小跳、长按 0.95 秒空中滑翔、空中二次振翅蓄力以及离开陆地仍可起跳的土狼时间。
3. 军团金字塔阶梯堆叠物理：当军团规模超过 6 人时，后排僵尸自动按阶梯层级在 Y 轴向上堆叠，上层僵尸踩在下层僵尸肩膀上奔跑，大幅增强翻越障碍与收集高空宝箱的攀爬能力。
4. 载具推挤受力与底盘悬挂下沉动力学：在 [Vehicle.js](file:///Users/fanchuang/Documents/zombie_game/src/entities/Vehicle.js) 中实现悬挂受力下沉与底盘向前倾角物理模拟，推挤时车底喷射地面摩擦火花，蓄力爆发时沿接触点计算角动量旋转升空。
5. 车顶平台跑酷与高空飞跃解耦：重构载具三层判定，空中起跳飞跃不再误触发推车，支持平滑跳上轿车、校巴、坦克与客机车顶奔跑，跑离车顶边缘时重力自然下落。
6. 击中微顿帧打击感：在咬碎平民、斩碎炸弹或合力掀翻大型客机瞬间触发 0.04 至 0.06 秒画面微冻结与摄像机轴向微冲拳。

# 视觉资产、次级运动与氛围渲染

1. 帽子与软体物理次级摆动：在 [Zombie.js](file:///Users/fanchuang/Documents/zombie_game/src/entities/Zombie.js) 中为帽子增加阻尼弹簧方程，起跳时帽子向上悬空抛起，落地时向下挤压缓冲，奔跑时随步态节奏上下律动。
2. 载具多段物理碎裂与轮毂弹跳：在 [ParticleSystem.js](file:///Users/fanchuang/Documents/zombie_game/src/effects/ParticleSystem.js) 与 [Vehicle.js](file:///Users/fanchuang/Documents/zombie_game/src/entities/Vehicle.js) 中实装四枚橡胶车轮的地面弹跳重力物理与金属破片飞溅。
3. 全局变身环境色温通道：在 [Renderer.js](file:///Users/fanchuang/Documents/zombie_game/src/engine/Renderer.js) 中为海啸、神龙、气球、巨型机甲、暗影武士、橄榄球、黄金狂热与 UFO 建立专属环境色调滤镜。
4. 无缝视差平铺与软过渡羽化：在 [Renderer.js](file:///Users/fanchuang/Documents/zombie_game/src/engine/Renderer.js) 中彻底移除镜像翻转，采用正向连续平铺搭配 4 像素重叠出血与 90 像素软渐变羽化，根除地标变形与垂直接缝。
5. 平民职业与同化服饰继承：[Civilian.js](file:///Users/fanchuang/Documents/zombie_game/src/entities/Civilian.js) 支持上班族、建筑工人、度假游客与记者四大职业，被感染后新僵尸直接继承原平民的衣服颜色与安全帽等配饰。

1. 逆向动态车流与来袭警示：在 [LevelGenerator.js](file:///Users/fanchuang/Documents/zombie_game/src/systems/LevelGenerator.js) 中加入迎面驶来的逆向车辆，并在 [Renderer.js](file:///Users/fanchuang/Documents/zombie_game/src/engine/Renderer.js) 中在屏幕右侧闪烁红色三角叹号警示。

3. 东方神龙与气球狂欢变身：[Transformations.js](file:///Users/fanchuang/Documents/zombie_game/src/entities/Transformations.js) 实装神龙波浪穿梭飞行与全员轻盈氦气球高空浮游。
4. 连击狂热暴走机制：连续吞噬 8 名平民触发 5 秒金色狂热暴走，获得全屏磁吸、移速爆发与无敌冲锋。
5. 大脑奖杯里程碑展厅：在 [Missions.js](file:///Users/fanchuang/Documents/zombie_game/src/systems/Missions.js) 中集成阶段奖杯勋章与累计大脑进度。

# 音频工程与动态压缩器

1. Web Audio 动态压缩器防爆音：在 [Audio.js](file:///Users/fanchuang/Documents/zombie_game/src/engine/Audio.js) 中在主输出链路接入 DynamicsCompressorNode，彻底消除多复音同时发声导致的振幅过载失真。
2. 音高微抖动防机关枪效应：在跳跃、撕咬、金币与爆炸音效中加入正负 5% 的随机微小音高偏移，消除机械重复感。
3. 海啸水下低通滤波与专属音效：实装海啸水下滤波、蹦床弹跳音、狂热暴走号角、神龙长啸与警报鸣笛。
