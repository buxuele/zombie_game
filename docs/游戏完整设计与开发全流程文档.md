本文档系统记录僵尸狂潮在 Web 端的完整技术架构设计、已实现的物理与渲染算法、当前十项深度扩展特性，以及未来迁移至 iOS 原生 SpriteKit 版本的完整移植规范与蓝图。

# 项目技术架构与模块全景

1. 引擎与渲染层：
- 渲染器：[Renderer.js](file:///Users/fanchuang/Documents/zombie_game/src/engine/Renderer.js) 负责 1280 乘 720 高清画布的视差滚动背景、场景地标门户、光影体积光、软渐变无缝平铺与色相氛围覆盖。

- 音频合成引擎：[Audio.js](file:///Users/fanchuang/Documents/zombie_game/src/engine/Audio.js) 基于 Web Audio API 构建纯代码高拟真程序化音效，包含动态压缩器、微小音高抖动、海啸低通滤波与金币大调音阶。

2. 角色与实体层：

- 平民系统：[Civilian.js](file:///Users/fanchuang/Documents/zombie_game/src/entities/Civilian.js) 支持上班族、建筑工人、度假游客与新闻记者四大职业，具备惊慌奔跑与被咬病毒感染转移动画。

# 核心算法与数学公式

1. 军团波浪式起跳级联延迟算法：
后排僵尸起跳时间不与领头僵尸绝对同步，而是按照军团索引施加微小时间差，公式为第 i 只僵尸延迟时间等于 i 乘 0.02 秒。同时在空中长按时，通过空气阻力将下落加速度衰减至每秒平方 180 像素，形成滑翔滞空手感。

2. 载具碰撞三层解耦判定算法：
- 空中高飞：当僵尸处于空中且双脚 Y 轴坐标小于车顶高度减 18 像素时，判定为成功飞跃，不触发推车。
- 车顶平台奔跑：当僵尸下落且双脚坐标位于车顶高度上下公差带内，立即着陆在车顶平台上并重置空中状态。
- 地面推车与合力掀翻：当且仅当僵尸处于地面奔跑状态且触碰车头前保险杠时，进入推挤状态。推挤计时结束后若军团人数达标则以向上每秒 580 像素冲量与每秒 8 弧度角速度旋转掀翻。

3. 海啸冲浪与神龙蛇形身体正弦轨迹：
- 海啸波浪采用双层正弦多项式复合曲线，波峰顶点紧跟领头僵尸，水面高度动态托举僵尸并在领头僵尸前方生成白色翻滚卷浪。
- 东方神龙各身段节点采用沿时间轴与索引衰减的正弦相位差函数，第 i 个身体球体的中心 Y 轴等于基准高度加上正弦相位偏移，形成流畅无缝的龙躯游弋体态。

4. 连续吞噬连击狂热暴走机制：
玩家在未受到炸弹伤害的情况下连续吞噬 8 名平民，将触发持续 5 秒的狂热暴走状态。期间移动速度增加每秒 80 像素、镜头轻微震颤、获得 360 像素全屏金币大脑强力磁吸、触碰车辆自动掀翻并对地雷爆炸完全免疫。

# iOS 原生版本迁移蓝图与技术规范

1. 引擎与渲染架构映射：
- Web 端 Canvas 渲染器映射为 iOS 的 SKScene 与 SKSpriteNode 节点树。
- 视差背景使用 SKNode 搭配 runAction 进行无缝无限循环位移。
- 粒子特效使用 SKEmitterNode 实现轮胎破片与火花爆炸。

2. 物理与碰撞架构映射：
- 采用 SpriteKit 内置物理引擎 SKPhysicsBody 或保持纯代码自定义射线与 AABB 检测以维持最精准的手感一致性。
- 物理碰撞掩码配置包含军团掩码、平民掩码、载具平台掩码、金币大脑收集品掩码与炸弹掩码。

3. 音频系统映射：
- Web Audio API 振荡器与动态压缩器映射为 iOS 原生的 AVAudioEngine、AVAudioPlayerNode 与 AVAudioUnitEQ。

4. 数据持久化映射：
- Web 端 LocalStorage 升级为 iOS 的 UserDefaults 或 CoreData，支持 Game Center 云存档与成就同步。
