# 经典僵尸狂潮 PC 网页版全量开发提示词与顶级动画技术规范

## 项目概述与极致动画核心宗旨

请基于现代前端技术栈，独立开发一款高还原度、手感细腻、细节打磨极致的横版跑酷游戏。游戏核心玩法深度复刻经典手机游戏 Zombie Tsunami，专为 PC 浏览器端定制键鼠操作与宽屏视口。
开发的核心首要任务是彻底杜绝粗糙低劣的半成品质感，将动画效果、骨骼形变、物理反馈、粒子特效与人群动力学作为第一衡量标准，打造丝滑生动的视觉盛宴。

## 美术资产生成规范与工作流

你可以使用图像生成大模型生成全套高清 2D 精灵图资产，并按以下规格与切图流程处理：

1. 绿皮僵尸动作序列图：
生成纯白色背景的 12 帧连续奔跑循环步态、起跳瞬间身体拉长姿势、滞空双臂向上疯狂摆动姿势以及落地瞬间压缩姿势。

2. 经典载具四件套精灵图：
生成红色家用轿车需 4 人、黄色校巴大巴车需 8 人、迷彩重型坦克需 12 人以及客运飞机需 16 人，每辆车顶部均带有高对比度黄色发光人数指示标牌。

3. 超能变身立绘大图：
生成奔腾海啸巨浪、双眼发射激光的巨型机甲僵尸、暗影武士忍者僵尸、全副武装四分卫橄榄球僵尸、悬浮外星 UFO 飞碟与金光闪闪黄金僵尸。

4. 场景道具与求救平民图：

5. 自动化透明抠图与中心锚定：
在前端加载时，通过画布遍历像素将背景白色自动过滤为纯透明通道，以角色脚底中心为物理锚点进行切图，彻底消除跑动时的上下晃动与图像抖动。

## 极高标准动画效果与物理手感规范

1. 僵尸帧动画与弹性形变体系：
奔跑循环帧率跟随游戏行进速度动态线性缩放。
起跳瞬间触发纵向拉伸与横向收缩，滞空滑翔时双臂以正弦波高频上下挥动，着陆瞬间触发横向挤压与纵向扁平缓冲，并在脚底即时生成扩散白烟。

2. 军团级联波浪起跳与弹簧动力学：
多只僵尸奔跑时采用阻尼弹簧算法维持队伍有机聚合与拉伸。
玩家触发跳跃时，跳跃指令从领头僵尸向队尾以 0.02 秒逐个向后传递，呈现极具韵律感的波浪跃起效果。

3. 车辆实体阻挡与空翻爆破打击感：
当僵尸总数小于车辆要求人数时，车辆为刚体实体阻挡墙，僵尸无法穿透车辆，撞击产生金属火花与前排僵尸阵亡，玩家必须跳跃从车顶越过。
当僵尸总数达到或超过车辆要求人数时，车辆阻挡碰撞瞬间解除，赋予向右上方的力矩与线速度，触发 360 度空翻旋转、外层烈焰火球、内层浓黑烟雾粒子、多轴镜头剧烈震屏以及黄色奖励文字弹射飘起。

4. 平民感染绿色毒雾爆发：
平民在路边持续上下雀跃挥手，被僵尸咬中瞬间定格并触发放射状绿色感染毒雾冲击波，原地弹出加一大脑发光飘字，新生成的僵尸伴随弹性缩放从小变大跳跃加入队伍。

5. 超能变身全屏视效：
海啸状态下生成波浪流体动态粒子，巨型僵尸状态下发射带脉冲抖动与高光光晕的红色贯穿激光死光，忍者状态下挥刀产生白色刀光残影拖尾。

## 核心操作与平台跳跃手感参数

1. 空格键或鼠标左键短按：
初始赋予 260 像素每秒的跳跃冲量，松开按键瞬间立即截断 55% 垂直速度，实现精准敏捷的轻点小跳。

2. 空格键或鼠标左键长按：
长按维持向上浮力，实现平滑滑翔，单次跳跃滞空时间上限锁定在 0.42 秒，最大起跳顶点高度严格限制在 160 像素以内，严禁飞出屏幕上方。

3. 辅助按键支持：
P 键或 Esc 键暂停游戏，M 键切换音效与背景音乐静音。

## 网页工程架构与技术栈

1. 核心技术选型：
采用 HTML5、TypeScript 或现代原生 JavaScript、Pixi.js 或 Phaser 游戏引擎、Web Audio API 网页音频系统，工程构建使用 Vite。

2. 视口适配：
锁定 16 比 9 宽屏分辨率，例如 1280 乘以 720，在任何尺寸的 PC 浏览器中均保持等比缩放与居中显示，黑边优雅填充。

3. 本地存储：
使用 LocalStorage 保存玩家金币、大脑总数、最高奔跑距离、已购买帽子与技能等级。
