# 僵尸狂潮自定义背景与图片替换指南

本文档说明如何将游戏中的背景与贴图替换为你自己喜欢的插画、像素画或实景全景图，完全摆脱 AI 质感，打造专属游戏视觉风格。

# 图片存放目录与自动加载机制

游戏引擎已升级为智能多级资源加载架构：
- 第一优先级：自动检测并加载 [public/backgrounds](file:///Users/fanchuang/Documents/zombie_game/public/backgrounds) 目录下的用户自定义图片。
- 第二优先级：加载 [public/images](file:///Users/fanchuang/Documents/zombie_game/public/images) 目录下的基础图片。
- 第三优先级保底：若未检测到任何图片文件，渲染器自动调用纯手绘风格高精扁平矢量插画算法，纯代码生成落日天际线、热带海滩与沙漠金字塔，确保零模糊、零扭曲、零 AI 异样感。

# 替换文件命名规范

只需要将你准备好的图片重命名为以下指定文件名，直接放入 [public/backgrounds](file:///Users/fanchuang/Documents/zombie_game/public/backgrounds) 文件夹即可：

1. 城市落日与天际线背景：
- 文件名：city.png 或 city.jpg 或 city.webp
- 对应关卡：0 至 700 米城市街区与高架路段。
- 建议画面：现代都市天际线、落日晚霞、赛博朋克夜景或像素都市长卷。

2. 阳光海滩与热带椰林背景：
- 文件名：beach.png 或 beach.jpg 或 beach.webp
- 对应关卡：1000 至 1800 米海滨公路与木质栈道路段。
- 建议画面：热带海岸线、湛蓝海洋、沙滩椰树或阳光海景。

3. 黄金沙漠与金字塔背景：
- 文件名：desert.png 或 desert.jpg 或 desert.webp
- 对应关卡：2150 米及以上的沙漠与绿洲路段。
- 建议画面：金黄色沙丘、古埃及金字塔群、戈壁夕阳或荒野峡谷。

4. 穿山隧道暗黑管廊背景：
- 文件名：tunnel.png 或 tunnel.jpg 或 tunnel.webp
- 对应关卡：700 至 1000 米地下隧道穿行路段。

5. 跨海悬索大桥背景：
- 文件名：bridge.png 或 bridge.jpg 或 bridge.webp
- 对应关卡：1800 至 2150 米钢铁大桥路段。

# 最佳画质与尺寸建议

1. 分辨率与长宽比：
推荐使用 1920 乘 1080 像素或 1280 乘 720 像素的横版 16 比 9 画面。

2. 边缘无缝循环：
推荐使用左右两侧色调与地平线高度相近的全景画作。渲染器已内置左右边界 90 像素软渐变羽化混合，即便普通长图也能实现平滑视差滚动。

3. 即时生效方式：
图片放入 [public/backgrounds](file:///Users/fanchuang/Documents/zombie_game/public/backgrounds) 文件夹后，无需重新编译，直接在浏览器中按下刷新按键即可实时生效。
