============================================================
僵尸狂潮 PC 网页版 - 自定义背景与图片放置目录
============================================================

你可以直接将自己喜欢的无水印、高清晰度背景图片放入此文件夹，
游戏将自动优先加载此文件夹中的图片！

支持的文件名与格式（PNG / JPG / WEBP）：
1. city.png 或 city.jpg     -> 对应 0~700m 城市落日/夜景天际线背景
2. beach.png 或 beach.jpg   -> 对应 1000~1800m 阳光海滩与椰林背景
3. desert.png 或 desert.jpg -> 对应 2150m+ 黄金沙漠与金字塔背景
4. tunnel.png 或 tunnel.jpg -> 对应 700~1000m 穿山隧道背景（可选）
5. bridge.png 或 bridge.jpg -> 对应 1800~2150m 跨海大桥背景（可选）

图片规格建议：
- 分辨率：推荐 1920x1080 或 1280x720 像素
- 画面：横向全景长图，左右边缘色调尽量保持连续无硬切边
- 生效方式：放入图片后，刷新浏览器（Cmd+R / F5）即可立即生效！
