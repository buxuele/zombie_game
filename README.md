# 僵尸狂潮 PC 网页版

# 最高优先级核心体验要求

1. 载具前置等待是游戏的核心体验。轿车、校巴、坦克和客机在军团接触车头时，必须先进入多人合力推车动画，不得瞬间结算。
2. 满编推车等待时长为 0.42 秒。人数不足时仍需推车 0.75 秒，让玩家有机会在等待期内起跳越过车辆。
3. 推车时至少显示多名僵尸同时发力，包含同步踏步、前倾身体、双手推撑、队形快速集结、悬挂压缩、车身倾斜、摩擦火花、镜头震动和金属受力音。
4. 推车队形必须比奔跑队形更紧凑。接触载具瞬间军团要合并抱紧，绝不允许出现先散开再收拢的视觉，编队切换时不得残留弹簧动量。
5. 等待期间玩家可以起跳取消本次推车。取消后车辆保持原位，僵尸军团恢复正常奔跑和跳跃。
6. 满编等待结束后掀翻车辆。人数不足等待结束后，先播放下降音阶的失望音效，再损失前排僵尸并退出本次推车，不得瞬间判定失败。
7. 跳跃距离适度增加，必须能跨越车辆顶部和常见断崖，同时保持完整画面可见与车顶平台判定稳定。
8. 自动化测试必须覆盖四类载具、成功等待、失败等待、多人推车、跳跃取消和失败音效。
9. 暂停只冻结画面，不得弹出任何菜单。恢复方式为按空格、回车或点击顶部继续按钮。游戏期间暂停必须可见且可点击，不得被遮罩层拦截。

僵尸狂潮 PC 网页版是一款基于 HTML5 Canvas 与原生 JavaScript 开发的高性能横版跑酷游戏。游戏深度还原了经典手机游戏僵尸尖叫的狂欢感染玩法，支持无限流式地形生成、动态多僵尸军团编队、八大魔幻变身道具、真实悬挂阻尼推车物理、幸运刮刮乐抽奖以及全套基因商店与悬赏任务系统。

# 核心玩法与特色系统

1. 僵尸军团与动态编队引擎：
- 玩家操控不断壮大的僵尸群，通过感染幸存者持续扩充军团规模。
- 采用独立异相步频引擎与动态双列波浪编队算法，每只僵尸具备独立的步频、抬腿、挥臂与下颌张合动作，展现生动群落动态。
- 起跳采用快速波浪级联机制，单个后排最多延迟 0.16 秒，领头僵尸即时响应，整组保持连贯跃起。

2. 行人智能避险与智能断崖刹车机制：
- 彻底解决行人原地乱动或自行走入断崖陷阱的逻辑缺陷。
- 行人平时自然原地站立守候，双臂自然下垂，绝不自行向右走动或跳舞投崖。
- 当僵尸军团逼近触发惊恐逃跑时，行人向前奔跑并持续进行前方地面探测。若前方探测为断崖深坑，行人立即在悬崖边缘紧急刹车驻足，抱头惊恐颤抖，绝不主动跳崖自杀。

3. 开阔天空背景与全景沉浸视野：
- 地面基线高度由 540 像素降低至 580 像素，道路高度缩减至 140 像素。
- 全景天空与大自然生态背景的可视高度与画面占比扩大至全屏的 80.5% 以上，带来辽阔恢弘的大世界全景沉浸感。
- 全场景实体、车辆、行人、金币与陷阱全面自适应对齐最新地面基线。

4. 真实载具阻尼碰撞与推车物理：
- 场景中包含小汽车、公交车、坦克与民航客机四类载具。
- 支持车顶跳跃踩踏与正面硬性阻尼推车。多名僵尸会快速集结并同步推撑，满编 0.42 秒后掀翻；人数不足时先推车 0.75 秒，玩家仍可起跳越过，失败后播放失望音效再损失前排僵尸。

5. 六大超强道具变身系统：
- 海啸洪流：召唤滔天海啸巨浪摧毁沿途一切障碍，持续时间优化为紧凑的 7 秒。
- 巨型机甲：化身双足重装机甲，胸口激光炮自动扫射前方一切障碍。
- 中国神龙：金鳞神龙腾空飞舞吞噬沿途障碍与车辆，持续时间优化为极速爆发的 3.5 秒。
- 橄榄球员：重装橄榄球四分卫，无视一切地雷与车辆正面冲撞。
- 忍者分身：双跳滞空与狂暴飞镖风暴。
- 黄金点金：全场景障碍金化点石成金。

6. 单图全屏视差滑动与零拼缝多生态轮换系统：
- 采用单图自适应缩放与生态进度平滑滑动技术，彻底根除横向拼接硬缝，全景丝滑流动。
- 支持大都会夜景、热带海岸、黄金沙漠、日落峡谷、未来基地、清雅荷花池畔与中世纪古堡庄园七大连续生态，结合历史过滤机制循环交替呈现，绝不单调重复。
- 全生态道路地面线条统一规范：第一道为高反差实线，第二道严格统一为规整美观的虚线。
- 开放玩家自定义背景插槽，放入图片即可无缝生效。

7. 精致交互与黑市商店系统：
- 顶部游戏状态栏配置实时动态金币倍率指示胶囊，狂潮变身期间高亮闪耀。
- 启动主界面小僵尸军团小剧场：主菜单顶部配备动态小僵尸整齐踏步巡游画布，支持光标悬停加速与戳击起跳吐露幽默出征气泡，彻底告别呆板。
- 基因与补给黑市小剧场：顶部配备实时互动的贪财独眼僵尸掌柜，身着精致马甲佩戴单片金丝眼镜，具备贪婪搓手呼吸微动效与戳击互动吐槽；支持属性点阵进度与已满级高质感标签；操作按键文字严谨简洁，彻底告别繁杂符号；个性装扮专区配备装扮试穿魔镜，可实时预览小僵尸试穿搭配。
- 零打扰暂停交互：暂停仅冻结游戏画面，绝不弹出任何菜单遮挡战场；顶部按钮在暂停与继续之间切换，并配一行不可点击的轻提示告知恢复方式，防止玩家切走窗口后忘记游戏仍在运行。
- 游戏底部常驻社交入口：左侧固定展示 GitHub 项目主页与 X 主页链接，带安全的外链属性，鼠标悬停高亮。
- 军团覆灭界面采用尸潮事故现场报告海报：非对称双栏头部、倾斜评级印章、现场报告条、三格等宽记分牌与整条主行动按钮，配证物胶带与纸张噪点纹理，彻底告别居中卡片堆叠。
- 动态段位评级与趣味死因鉴定，评级分 C、B、A、A+、SS、SSS 六档并按档位换色，战败后支持一键直达刮刮乐翻盘。

8. 细腻动画与全套视觉细节系统：
- 动态离地高度阴影与环境光照：丧尸起跳腾空时地面阴影随高度实时缩放淡化，落地瞬间展开；载具配备车头大灯锥形光束，道路配置路灯体积光锥。
- 尊贵东方神龙大招：金角皇冠与灵眸中国龙首、连续蜿蜒流线龙身、四组锋利龙爪与盘旋金色火龙珠，带来震撼视觉表现。
- 诙谐幽默微动效：平民被咬瞬间弹跳惊叹号、惊恐汗珠与蓬松变身白烟；丧尸阵亡时生成金色光环小天使幽灵缓缓升天。
- 纯粹物理碰撞拾取：彻底移除不劳而获的自动磁吸机制，金币与高空宝箱必须通过精准走位与跳跃真实触碰收集。

# 项目目录结构

1. 源代码目录 src：
- engine: 包含游戏主循环 Game.js、图形渲染器 Renderer.js、原生音效合成器 Audio.js、输入系统 Input.js 以及资源加载器 AssetLoader.js。
- entities: 包含僵尸实体 Zombie.js、军团管理 ZombieHorde.js、载具推车 Vehicle.js、幸存者 Civilian.js、障碍物 Obstacle.js 与八大变身系统 Transformations.js。
- systems: 包含无限地形关卡生成 LevelGenerator.js、生态区域管理 BiomeManager.js、基因与装扮商店 Shop.js、幸运刮刮乐 ScratchCard.js、悬赏任务 Missions.js、本地数据存档 Storage.js 与运行时日志 Logger.js。
- effects: 包含动态粒子系统 ParticleSystem.js 与飘字动画 FloatingText.js。
- style.css: 现代化深岩灰视觉设计系统，严格遵循 12 像素卡片与 8 像素按键规范。
- main.js: 游戏主入口与全局界面状态流转控制器。

2. 静态资产目录 public：
- backgrounds: 存放 4K 与 5K 高清全景背景城市、海滩与沙漠图片。
- images: 存放各类精灵图、龙首与道具贴图。

3. 专用文档目录 docs：
- 存放需求说明书、全流程开发文档、背景替换指南、运行指南与开发哲学总结。

4. 测试套件目录 tests：
- game_logic.test.js: 覆盖跳跃物理、推车碰撞、多人推车、失败等待、跳跃取消、变身属性、动态高度阴影、镜头稳定性、背景平滑过渡、三大场景自适应音乐、陷阱高对比度警示、平民深渊坠落重力、严密实体接触判定、载具人数门槛刚性校验、载具路面静止驻停、载具精灵贴图优先渲染、平民濒死惊恐尖叫与挣扎动作、零接缝视差背景平移、多生态七大背景防重复轮换、全生态路面第二道虚线规范、黑市商店金币经济系统、平民断崖刹车避险机制以及降低路面高度背景扩增比例等全量自动化测试断言。

# 快速启动与操作指南

1. 一键启动本地服务：
- 执行根目录启动脚本：
./just_run.sh
- 或通过 npm 运行开发服务器：
npm run dev

2. 游戏按键控制：
- 跳跃与滞空飞行：长按或短按空格键，或使用鼠标左键点击游戏画面。
- 游戏暂停与继续：键盘 P 键或 Esc 键。
- 声音静音切换：键盘 M 键。
- 实时调试日志展开与收起：键盘 L 键。

3. 运行全自动化单元测试：
- 在终端执行如下命令：
node tests/game_logic.test.js

# Git 极速同步与仓库管理

1. 日常一键代码提交与推送：
- 在项目根目录下执行：
./gg.sh 你的提交说明
- 若不输入提交说明，直接执行 ./gg.sh 即可自动使用当前时间戳完成暂存、提交并推送到 GitHub main 分支。

2. 新项目通用一键创建与推送：
- 执行 scripts/git_init_push.sh 项目名 你的Token，即可自动通过 GitHub API 创建远端仓库并推送。
